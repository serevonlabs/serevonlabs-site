Serevon Labs website v6 - Modern Business Redesign
Date: 2026-10-03

Major changes
- Increased desktop content width from 1180px to 1540px, with an ultra-wide 1640px layout on very large screens.
- Rebuilt the homepage hero to use wide displays more effectively.
- Replaced the ContinuCam-focused hero visual with a modern business-software workspace illustration built entirely in HTML/CSS.
- Added web, enterprise, Android/iOS, Windows, and integration messaging throughout the homepage.
- Removed the large address overlay from the About/Company graphics.
- Enlarged and reframed the business capability graphics so they function as actual visual content instead of address cards.
- Added modern service cards, process cards, glass panels, gradients, responsive dashboard artwork, and improved spacing.
- Updated About, Apps, and Support pages to match the broader business development positioning.
- Kept ContinuCam as a featured Serevon Labs product rather than the primary company identity.
- Preserved appsupport@serevonlabs.com as the public contact/support email.
- Added optional Adobe Stock guidance in ADOBE_STOCK_OPTIONS.md. The live design does not depend on unlicensed stock assets.

Responsive design
- Desktop: optimized for 1440px, 1920px, and ultra-wide displays.
- Tablet: transitions to two-column cards and single-column hero content.
- Mobile: simplified dashboard artwork and single-column content.

Deployment
- Upload the contents of this folder to the same static web host currently serving serevonlabs.com.
- Existing ContinuCam localized privacy/terms files and Azure static web app configuration are preserved.
